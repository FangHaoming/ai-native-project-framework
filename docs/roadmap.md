# Roadmap

## Phase 1: Project Harness

- Repository layout.
- `AGENTS.md`.
- Spec template and lifecycle folders.
- Controlled CLI skeleton.
- Observability gateway policy.

## Phase 2: Real Stack Binding

- Add chosen web and API framework.
- Add database and migration tooling.
- Add local development environment.
- Add affected test detection.
- Add preview environments.

## Phase 3: Control Plane

- Spec state machine.
- Branch and PR automation.
- Human approval gates.
- Audit log.
- Role-based agent permissions.

## Phase 4: AI Ops

- Connect logs, traces, metrics, and deploy history.
- Add incident specs.
- Add runbook execution with approval.
- Add model-readable operational summaries.

## Phase 5: Scale

- Multi-project catalog.
- Shared design system and SDKs.
- Cross-repo dependency graph.
- Organization-level governance and evaluation.
